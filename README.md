# Marketing Funnel & Conversion Analysis - Task 3

## 📌 Présentation du Projet
Ce projet fait partie de mon stage chez **Future Interns**. L'objectif est d'analyser le comportement des utilisateurs sur une plateforme e-commerce pour identifier les points de friction dans le parcours d'achat.

## 🛠️ Technologies Utilisées
* **Python** (Pandas pour le traitement de données)
* **Plotly** (Visualisations interactives)
* **Jupyter Notebook** (VS Code)

## 📊 Résultats Clés
* **Taux de Conversion :** 1.99%
* **Revenu Total Analysé :** 2.89M USD
* **Insight Majeur :** La plus grosse déperdition d'utilisateurs se situe entre la vue du produit et l'ajout au panier.

* `analyse_entonnoir.ipynb` : Le notebook contenant tout le code et l'analyse.
